## 📝 Sobre o Projeto
O HeróisFlix foi desenvolvido com o objetivo de criar uma experiência visual inspirada nas grandes plataformas de streaming, focada totalmente no universo cinematográfico da Marvel.

A aplicação apresenta uma interface moderna, organizada e totalmente responsiva, permitindo que os usuários explorem filmes da franquia de maneira dinâmica e intuitiva.

Além da experiência visual, o projeto também serviu para fortalecer meus conhecimentos em desenvolvimento Front-end, responsividade, organização de layouts e manipulação dinâmica de conteúdo utilizando JavaScript.

## 🌟 Funcionalidades Principais:
### 🎥 Banner em Vídeo
* Reprodução automática de vídeo.

* Destaque visual para lançamentos.

* Experiência mais imersiva para o usuário.

* Interface inspirada em plataformas reais de streaming.
  
### 🎬 Catálogo de Filmes
* Exibição dinâmica de filmes da Marvel.
* Cards organizados com:
    * Capa do filme
    * Nome
    * Duração
    * Descrição
    * Botão de acesso

### 📱 Responsividade Completa
*O projeto foi adaptado para diferentes dispositivos:
  * Smartphones
  * Tablets
  * Notebooks
  * Monitores widescreen

### 🎨 Interface Moderna
* Design inspirado em streamings profissionais.
* Paleta de cores com destaque em vermelho.
* Layout limpo e organizado.
* Navegação simples e intuitiva.

## 🛠️ Tecnologias Utilizadas
A pilha de tecnologia escolhida para este projeto foca na performance e na fidelidade visual:

🔹 HTML5
    * Estrutura semântica da aplicação.
    * Organização dos elementos da interface.

🔹 CSS3
    * Flexbox
    * Grid Layout
    * Responsividade com Media Queries
    * Hover Effects
    * Estilização moderna
    * Organização visual dos cards

🔹 JavaScript
    * Manipulação do DOM
    * Estrutura dinâmica com arrays e objetos
    * Renderização automática dos filmes
    * Interatividade da interface
